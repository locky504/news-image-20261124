A program that draws the world news of Tuesday 24 November 2026 as a one-page newspaper front page ("The World Today") and writes it to /output/entry.png.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies the finished `entry.png` — drawn by `draw.py` from the verified headlines of 24 November 2026 — to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png` when that is set). Node standard library only; repeated runs write identical bytes.
